# Streaming latency investigation

This folder collects the streaming experiment scripts and recorded outputs.

- `stream-smoke-3ahEMJTX/`: smoke-test script and output.
- `streaming-p03DQ6ts/`: experiment script, settings, API-call records,
  inventory, appendix note, and failure record.

These files were copied from the original `results/` directories, which
remain unchanged. Inspect `run_failure.json` and the recorded calls before
treating the experiment as complete. Relative paths in scripts may still
assume execution from the repository root.
